# 📚 세계 문학 퀴즈 프로그램 (World Literature Quiz)

파이썬 클래스와 JSON 데이터 처리를 활용한 콘솔 기반 퀴즈 게임 프로젝트입니다.

## 1. 프로젝트 개요

이 프로젝트는 사용자가 세계 문학 작가와 작품에 관한 퀴즈를 풀고, 직접 문제를 등록하거나 관리할 수 있는 프로그램입니다. 객체 지향 프로그래밍(OOP) 원칙을 적용하여 설계되었으며, 모든 데이터는 `state.json` 파일에 저장되어 프로그램 종료 후에도 유지됩니다.

- Python 버전: 3.10 이상
- 외부 라이브러리 없이 표준 라이브러리만 사용

## 2. 퀴즈 주제 선정 이유

- **지식의 보편성**: 세계 문학은 시대를 초월하여 사랑받는 주제이며, 퀴즈를 통해 상식을 점검하기에 적합합니다.
- **데이터 확장성**: 작가, 작품명, 연도 등 다양한 형태의 문제를 구성하기 용이하여 추후 기능 확장(4지선다 등)에 유리합니다.
- **학습 효과**: 퀴즈를 푸는 과정에서 자연스럽게 문학적 소양을 쌓을 수 있도록 기획하였습니다.
- 현재 등록된 기본 문항 수: 5개

## 3. 실행 방법

프로그램을 실행하려면 Python이 설치되어 있어야 하며, 아래 명령어를 순서대로 입력합니다.

```bash
# 1. 저장소 클론
git clone https://github.com/본인의계정/저장소이름.git

# 2. 디렉토리 이동
cd 저장소이름

# 3. 최신 코드 반영
git pull origin main

# 4. 프로그램 실행
python main.py
```

## 4. 기능 목록

| 기능 | 설명 |
|---|---|
| 퀴즈 풀기 | 등록된 문제를 순차적으로 풀고 정답 여부를 즉시 확인 |
| 퀴즈 등록 | 사용자가 새로운 퀴즈(문제, 선택지 4개, 정답)를 직접 추가 |
| 퀴즈 목록 보기 | 저장된 모든 퀴즈의 목록 확인 |
| 최고 점수 확인 | 역대 게임 플레이 중 기록한 최고 점수 출력 |
| 데이터 영속성 | 모든 퀴즈와 최고 점수를 `state.json`에 저장하여 재시작 후에도 유지 |
| 잘못된 입력 처리 | 숫자 변환 실패, 범위 초과, 빈 입력, Ctrl+C/EOF 발생 시 안전하게 재입력 또는 종료 |

## 5. 파일 구조

```
.
├── main.py              # 프로그램의 진입점 및 메뉴 시스템 로직
├── question_model.py    # Question 클래스 정의 (데이터 구조)
├── quiz_brain.py        # QuizBrain 클래스 정의 (게임 진행 로직)
├── quiz_data.py         # 초기 기본 퀴즈 데이터
├── state.json           # 퀴즈 및 최고 점수 저장 데이터 파일 (UTF-8)
├── .gitignore           # Git 제외 파일 설정
└── README.md            # 프로젝트 문서
```

## 6. 데이터 파일 설명 (state.json)

- **역할**: 프로그램의 상태를 영구적으로 보관하는 데이터베이스 역할
- **형식**: JSON
- **인코딩**: UTF-8
- **저장 항목**
  - `high_score`: 사용자의 역대 최고 점수 (정수형)
  - `questions`: 등록된 전체 퀴즈 리스트 (객체 배열, 각 객체는 문제/선택지/정답 포함)

파일이 없거나 손상된 경우 기본 퀴즈 데이터로 초기화합니다.
