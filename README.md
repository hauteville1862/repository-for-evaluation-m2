# 📚 세계 문학 퀴즈 프로그램 (World Literature Quiz)

파이썬 클래스와 JSON 데이터 처리를 활용한 콘솔 기반 퀴즈 게임 프로젝트입니다.

## 1. 프로젝트 개요

사용자가 세계 문학 작가와 작품에 관한 4지선다형 퀴즈를 풀고, 직접 문제를 등록하거나 목록을 확인할 수 있는 콘솔 프로그램입니다. `Question`과 `QuizBrain` 두 클래스로 데이터와 게임 진행 로직을 분리했으며, 모든 데이터는 JSON 파일에 저장되어 프로그램을 종료해도 유지됩니다.

- Python 버전: 3.10 이상
- 외부 라이브러리 없이 표준 라이브러리만 사용

## 2. 퀴즈 주제 선정 이유

- **지식의 보편성**: 세계 문학은 시대를 초월하여 사랑받는 주제이며, 퀴즈를 통해 상식을 점검하기에 적합합니다.
- **데이터 확장성**: 작가, 작품명, 수상 이력 등 다양한 형태의 문제를 구성하기 용이하여 추후 기능 확장에 유리합니다.
- **학습 효과**: 퀴즈를 푸는 과정에서 자연스럽게 문학적 소양을 쌓을 수 있도록 기획했습니다.
- 현재 등록된 기본 문항: 5개 (레 미제라블, 1984, 데미안, 위대한 개츠비, 죄와 벌 관련 작가 퀴즈)

## 3. 실행 방법

```bash
# 1. 저장소 클론
git clone https://github.com/hauteville1862/repository-for-evaluation-m2.git

# 2. 디렉토리 이동
cd repository-for-evaluation-m2

# 3. 최신 코드 반영
git pull origin main

# 4. 프로그램 실행 (main.py가 있는 apps 폴더에서 실행)
cd apps
python main.py
```

> `data.json`은 `main.py`와 같은 `apps` 폴더 안에서 상대 경로로 읽고 씁니다. 다른 위치에서 실행하면 데이터 파일을 찾지 못하니 반드시 `apps` 폴더 안에서 실행하세요.

## 4. 기능 목록

| 기능 | 설명 |
|---|---|
| 퀴즈 시작 | 등록된 5개 문제를 순서대로 풀고 정답 여부를 즉시 확인 |
| 퀴즈 추가 | 문제, 보기 4개, 정답 번호(1~4)를 입력받아 새 퀴즈 등록 |
| 퀴즈 목록 보기 | 저장된 모든 퀴즈와 정답 번호를 확인 |
| 최고 점수 확인 | 역대 플레이 중 기록한 최고 점수를 출력 |
| 데이터 영속성 | 퀴즈 목록과 최고 점수를 `data.json`에 저장하여 재실행 후에도 유지 |
| 잘못된 입력 처리 | 정답 입력 시 1~4 이외의 값은 재입력 요구, 퀴즈 추가 시 숫자 아닌 정답 입력 시 재입력 요구 |

## 5. 파일 구조

```
.
├── apps/
│   ├── main.py              # 프로그램 진입점 및 메뉴 로직 (퀴즈 시작/추가/목록/점수)
│   ├── question_model.py    # Question 클래스 정의 (문제, 보기, 정답)
│   ├── quiz_brain.py        # QuizBrain 클래스 정의 (문제 출제, 채점 로직)
│   └── data.json            # 퀴즈 및 최고 점수 저장 파일 (UTF-8, 실행 시 자동 생성/갱신)
├── docs/
│   └── 평가기준.md           # 미션 평가 기준 문서
├── .gitignore
└── README.md
```

## 6. 데이터 파일 설명 (data.json)

- **역할**: 프로그램의 상태(등록된 퀴즈, 최고 점수)를 영구적으로 보관
- **위치**: `apps/data.json` (프로그램 실행 위치 기준 상대 경로)
- **형식**: JSON, UTF-8 인코딩
- **스키마**
  - `high_score` (정수): 역대 최고 점수
  - `questions` (배열): 각 원소는 다음 필드를 가진 객체
    - `text` (문자열): 문제 내용
    - `options` (문자열 배열, 4개): 보기 목록
    - `answer` (정수, 1~4): 정답 번호
- **초기 실행 시 동작**: `data.json`이 없으면 `{"high_score": 0, "questions": []}`로 초기화한 뒤 진행
