# 📚 Python Literature Quiz Game

이 프로젝트는 파이썬의 객체 지향 프로그래밍(OOP)을 연습하기 위한 퀴즈 게임입니다.

## 🛠 사용 기술
- Python 3.x
- Git / GitHub

## 📝 주요 기능
- **객체 지향 구조**: `Question`, `QuizBrain` 클래스를 활용한 모듈화
- **데이터 분리**: 퀴즈 데이터를 별도 파일(`quiz_data.py`)로 관리
- **점수 시스템**: 실시간 정답 확인 및 최종 점수 합산

## 🚀 실행 방법
```bash
python main.py
