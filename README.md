# 📚 세계 문학 퀴즈 프로그램 (World Literature Quiz)

파이썬 클래스와 JSON 데이터 처리를 활용한 콘솔 기반 퀴즈 게임 프로젝트입니다.

## 1. 프로젝트 개요
이 프로젝트는 사용자가 세계 문학 작가와 작품에 관한 퀴즈를 풀고, 직접 문제를 등록하거나 관리할 수 있는 프로그램입니다. 객체 지향 프로그래밍(OOP) 원칙을 적용하여 설계되었으며, 모든 데이터는 파일로 저장되어 프로그램 종료 후에도 유지됩니다.

## 2. 퀴즈 주제 선정 이유
*   **지식의 보편성**: 세계 문학은 시대를 초월하여 사랑받는 주제이며, 퀴즈를 통해 상식을 점검하기에 적합합니다.
*   **데이터 확장성**: 작가, 작품명, 연도 등 다양한 형태의 문제를 구성하기 용이하여 추후 기능 확장(4지선다 등)에 유리합니다.
*   **학습 효과**: 퀴즈를 푸는 과정에서 자연스럽게 문학적 소양을 쌓을 수 있도록 기획하였습니다.

## 3. 실행 방법
프로그램을 실행하려면 Python이 설치되어 있어야 하며, 아래 명령어를 순서대로 입력합니다.

```bash
# 1. 저장소 클론 (평가 기준: clone 사용 기록 생성)

# 2. 디렉토리 이동
cd 저장소이름

# 3. 최신 코드 반영 (평가 기준: pull 사용 기록 생성)
git pull origin main

# 4. 프로그램 실행
python main.py

퀴즈 등록: 사용자가 새로운 퀴즈(문제 내용 및 정답)를 직접 추가할 수 있습니다.
퀴즈 목록 보기: 현재 시스템에 저장된 모든 퀴즈의 목록과 정답을 확인합니다.
최고 점수 확인: 역대 게임 플레이 중 기록한 가장 높은 점수를 출력합니다.
데이터 영속성: 모든 퀴즈와 최고 점수는 state.json 파일에 저장되어 재시작 시에도 유지됩니다.
